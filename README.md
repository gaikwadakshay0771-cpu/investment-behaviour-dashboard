# Investment Behaviour Dashboard

**A Business Analytics Project using Microsoft Power BI**

## Project Overview

The Investment Behaviour Dashboard explores survey responses to understand investment preferences, investment objectives, reasons for investment, savings objectives, and stock-market interest.

This project was developed as part of my Business Analytics internship tasks with Cognifyz Technologies.

## Dataset Overview

- Total Records: 40
- Total Columns: 24
- Missing Values: 0
- Exact Duplicate Rows: 0
- Analysis Tool: Microsoft Power BI

## Dashboard Pages

### 1. Analysis
- Total Respondents
- Average Age
- Investment Interest
- Stock Market Interest
- Gender Distribution
- Investment Avenue Analysis
- Interactive Age, Gender and Duration slicers

### 2. Investor Insights
- Investment Objectives
- Reasons for Mutual Fund Investment
- Investment Avenue Mix
- Stock Market Interest by Objective
- KPI Cards

## Key Findings

| Finding | Result |
|---|---:|
| Mutual Fund Preference | 45% |
| Stock Market Interest | 87.5% |
| Capital Appreciation Objective | 65% |
| Better Returns - Mutual Fund Reason | 60% |
| Retirement Plan Savings Objective | 60% |
| Financial Consultants - Information Source | 40% |

## Project Limitations

- The analysis covers 40 survey respondents and should not be generalised to all investors.
- Numeric investment-score coding is not accompanied by a scale-definition document.
- Average investment duration is an approximate estimate based on category midpoints.
- Expected-return categories represent respondent expectations, not actual investment returns.
